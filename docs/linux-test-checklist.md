# Проверка PNG Streamer на Linux

Спасибо, что помогаешь! Понадобится 15–20 минут, микрофон и (желательно) OBS.
Отметь каждый пункт: ✅ работает, ❌ не работает (и что именно видно), ➖ не проверял.

**Окружение** — пришли вывод этих команд:
```bash
cat /etc/os-release | head -3
echo "$XDG_SESSION_TYPE $XDG_CURRENT_DESKTOP"
```

## 1. Запуск и установка
1. Скачай `PNGStreamer-*-x86_64.AppImage` в «Загрузки», выполни `chmod +x` и запусти двойным кликом или из терминала.
   Если не запускается — запусти из терминала и пришли весь вывод.
2. Появилось окно «Установка PNG Streamer». Оставь папку по умолчанию, включи оба флажка, нажми **Установить**.
   - [ ] программа перезапустилась уже из `~/Applications/PNGStreamer/`
   - [ ] в меню приложений есть PNG Streamer с иконкой лисёнка
   - [ ] на рабочем столе есть ярлык и он запускает программу
   - [ ] в «Загрузках» AppImage больше нет

## 2. Окно
- [ ] окно с обычной системной рамкой, его можно двигать, сворачивать, разворачивать и менять размер
- [ ] текст чёткий, шрифт не «квадратами», русские буквы на месте
- [ ] переключение разделов Запуск / Звук / Изображения / Настройки
- [ ] Настройки → язык English / Русский меняется сразу

## 3. Звук
- [ ] Звук → «Аудиосистема» и «Устройство» показывают твой микрофон
- [ ] выбери свой микрофон и говори: индикатор «Уровень сейчас» двигается
- [ ] включи шумоподавление — фоновый шум перестаёт двигать индикатор
- [ ] нажми **Сохранить**, перезапусти программу — выбор сохранился

## 4. Аватар и OBS
- [ ] Запуск: предпросмотр аватара меняет кадры, когда говоришь, и иногда моргает
- [ ] **Запустить** → статус «В эфире», появился адрес; **Копировать** копирует его
- [ ] открой адрес в браузере (или добавь «Браузер» в OBS) — аватар двигается вместе с голосом
- [ ] Изображения → «Добавить картинки» и перетаскивание PNG в окно добавляют картинку

## 5. Трей
- [ ] рядом с часами появился значок лисёнка (на GNOME нужно расширение AppIndicator)
- [ ] правый клик: меню со статусом, запуском сервера, профилями; переключение профиля работает
- [ ] закрытие окна крестиком прячет его в трей (было уведомление); «Открыть PNG Streamer» возвращает окно
- [ ] если значка в трее нет: Настройки → пункт «Сворачивать в трей» недоступен, а крестик закрывает программу

## 6. Автозапуск и повторный запуск
- [ ] запусти программу второй раз из меню — вместо второй копии появляется уже открытое окно
- [ ] Настройки → «Запускать вместе с системой» + «Запускать свёрнутым в трей», перезайди в систему — программа в трее

## Если что-то сломалось
Пришли файл `~/Applications/PNGStreamer/data/logs/app.log` и скриншот.
